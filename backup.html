StreamPulse Backup & Restore

📦 Create Backup

Downloads a ZIP containing your config.json, the current live session files (data/chat.json and data/chat-log.jsonl), all session archives, Twitch data snapshots, timers, banned hashtags, and highlights. Does not include your Twitch OAuth token (you'll need to re-auth after restore).
📦 Download Full Backup

📥 Restore from Backup

Upload a previously downloaded backup ZIP to restore all data. This will overwrite current stats, config, live session files, and session archives. StreamPulse reloads compatible in-memory data automatically, but restored connection and startup settings still require a restart.

⚙️ Auto-Backup Settings

When enabled, a backup ZIP is automatically saved to data/backups/ each time a session ends. The last 10 auto-backups are kept.
