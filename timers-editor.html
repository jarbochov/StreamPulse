Controls

Pause and Resume now work for countdowns and stopwatches. Set Stopwatch Base Time changes the stopwatch's reset value. Adjust Time adds or subtracts from the current displayed time without changing what reset returns to. Adjust Time works for both countdowns and stopwatches, and countdown subtraction to zero completes the timer.
