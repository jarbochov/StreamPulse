OBS Studio Setup (One-Time Script Install)
  1. Copy the canonical script path below (recommended so StreamPulse keeps it auto-updated).
  2. In OBS Studio, open Tools → Scripts, click +, and load streampulse-patterns.lua.
  3. Add a StreamPulse Pattern Background source in OBS (or click Add / Update in OBS in Tab 1).
  4. Edits in StreamPulse or Variable Settings sync straight into OBS automatically!
