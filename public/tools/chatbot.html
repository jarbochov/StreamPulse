Twitch Auto-Detected Moderators & Broadcaster Detecting…
How moderator status is determined:
• Twitch API: Channel moderators are auto-synced from Twitch (shown above).
• Chat Badges: Incoming chat from SocialStream with Moderator, Broadcaster, or Staff badges are detected in real time.
• Broadcaster: The channel owner is always granted full moderator privileges.
• Fallback list: Usernames listed above are always granted mod permissions across all platforms (ideal for YouTube/Kick mods or testing).

Incoming Raid Auto-Shoutout

Automatically welcome incoming raids and shout them out in chat.

Supported tokens: {{user}} (raider username), {{viewers}} (viewer count), plus all standard placeholders.

Poll & Bracket Chat Announcements

Automatically post messages to chat when polls and tournament matches start and finish.

Supported tokens: {title}, {choices} (one per line, e.g. !vote 1: Option), {commands}, {duration}, {winner}, {votes}, {percent}, {totalVotes}, {champion}, {prefix}, {tag}.

Tier List Chat Announcements

Automatically post messages to chat when community tier list voting opens and closes.

Supported tokens: {item}, {tier}, {tiers} (e.g. S, A, B, C, D, F), {commands}, {duration}, {votes}, {percent}, {totalVotes}, {agreement}, {subVotes}, {prefix}, {tag}.

Trivia Chat Announcements

Broadcast questions and reveal correct answers in chat during live trivia.

Supported tokens: {category}, {question}, {choices}, {commands}, {duration}, {seconds}, {answer}, {answerText}, {correctLetter}, {percent}, {votes}, {totalVotes}, {correctVotes}, {funfact}, {prefix}, {tag}.

Donation Chat Announcements

Thank donors in chat when a donation at or above the minimum arrives.

Tokens: {user}, {amount} (formatted as $1,234.00), {message}, {currency}, {source}, {total}, {goal}. The same donor and amount is announced once even if two sources report it. Any number placeholder can be shown as currency with |money, for example .

Donation chat announcements are currently disabled. Check the toggle above to configure templates and donor thresholds.

Chat Bot Tokens & Dynamic Arguments Guide Click to expand
Token What it does Example in Command Response Viewer types Bot replies
{{user}} Chatter name who typed the command Hey {{user}}, welcome in! !hi Hey Alice, welcome in!
{{target}} Target user from args (strips @; defaults to sender or fallback) Shoutout to @{{target}}! Check out twitch.tv/{{target}} !so @Bob Shoutout to @Bob! Check out twitch.tv/Bob
{{args}} All text typed after the command name Topic: {{args:Just chilling!}} !topic Coding session Topic: Coding session
{{arg.1}}, {{arg.2}} 1st, 2nd, etc. space-separated word. Supports fallbacks like {{arg.2:dogs}} {{user}} asks: {{arg.1:cats}} or {{arg.2:dogs}}? !compare tea coffee Alice asks: tea or coffee?
{{random min max}} Random dice roll or integer between min and max {{user}} rolled a {{random 1 6}} on a 6-sided die! !roll Alice rolled a 4 on a 6-sided die!
{{choice A|B|C}} Random pick from pipe-separated list 8-Ball: {{choice Yes!|No.|Ask again later.}} !8ball 8-Ball: Yes!

Tip: Click any tag above to copy it, or click "Insert placeholder" on any command to browse and insert tokens with live previews.
