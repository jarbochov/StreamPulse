OBS Studio Setup (macOS Metal / Windows / Linux)
  1. Download or locate streampulse-borders.lua (saved automatically in your StreamPulse data folder).
  2. In OBS Studio, open Tools → Scripts, click +, and add streampulse-borders.lua.
  3. Right-click any nested Bundle scene (e.g. Bundle - Webcam Full w/ Border) or Video Source → Filters.
  4. Remove any old obs-shaderfilter border layers, click + under Effect Filters, and choose StreamPulse Border.
  5. Leave the Profile dropdown on Auto (or pick a specific profile). Changes to borders or Variables auto-sync into OBS within 0.5s!
