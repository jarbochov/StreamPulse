OBS Studio Setup (One-Time Script Install)
  1. Copy the canonical script path below (recommended so StreamPulse keeps it auto-updated automatically).
  2. In OBS Studio, open Tools → Scripts, click +, and load streampulse-borders.lua.
  3. Open Live OBS Sources & Scenes, click Sync Live OBS, choose profiles per source or per scene, and click Apply Filter.
  4. Edits in StreamPulse or Variable Settings sync straight into OBS automatically!
