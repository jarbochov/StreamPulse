Chat Bot Dynamic Tokens & Actions 7 tokens
Click to expand Open in Chat Bot ↗

These special tokens are evaluated dynamically when a viewer runs a command or triggers a reply in chat. They resolve the caller, target user mentions, arguments, or roll random outcomes.

Token Description Example in Command Response Example Output
{{user}} Username of the chatter who ran the command (or $(user)) Hey {{user}}, welcome in! Hey Alice, welcome in!
{{target}} Target user from command args (strips @; falls back to sender or {{target:someone}}; also $(touser)) Shoutout to @{{target}}! twitch.tv/{{target}} Shoutout to @Bob! twitch.tv/Bob
{{args}} All arguments / text following the command name {{user}} asked: "{{args}}" Alice asked: "how are you?"
{{arg.1}}, {{arg.2}} 1st, 2nd, etc. space-separated word typed after the command. Supports default fallbacks like {{arg.2:dogs}} if omitted, and Nightbot syntax $(1), $(2) {{user}} asks: {{arg.1:cats}} or {{arg.2:dogs}}? Alice asks: tea or coffee?
{{viewers}} Viewer count of incoming raid in auto-shoutout or shoutout test (or $(viewers)) Welcome raiders from @{{user}} with {{viewers}} viewers! Welcome raiders from @Alice with 42 viewers!
{{random min max}} Evaluates a random integer or dice roll between min and max (inclusive) [Roll] {{user}} rolled a {{random 1 20}}! [Roll] Alice rolled a 19!
{{choice A|B|C}} Randomly picks one pipe-separated item (also {{pick A|B|C}}) 8-Ball: {{choice Yes!|No.|Ask again later.}} 8-Ball: Yes!
