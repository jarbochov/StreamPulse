StreamPulse Clips (Beta)

Beta: StreamPulse detects possible clip moments but does not create clips automatically. Review a candidate and create the Twitch clip manually while live. Twitch returns a temporary editing URL after creation. The published clip URL is saved with the candidate.

Detection Settings

These thresholds decide which live events become reviewable clip candidates. They do not create Twitch clips automatically.

Automatic detection

Turn automatic candidate detection on or off. Manual markers and historical analysis remain available when it is off.

Chat spike window

A chat spike is detected when the required number of messages arrives within the time window. For example, 20 messages in 60 seconds.

Default example: 20 chat messages within 60 seconds, with a 30-second cooldown.

Event triggers

Choose which stream events can create candidates, then set the minimum value for events that have one.
