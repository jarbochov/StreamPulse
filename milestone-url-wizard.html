URL Parameters Reference
Parameter Values Description
mode card, pill, streak, goal, stream_num Display layout of the overlay.
fontScale / scale Number, e.g. 1.2 Font size scaling factor (0.5 to 2.5). Adapts fluidly with viewport typography.
align center, left, right Horizontal alignment within browser source canvas.
theme glass, dark, transparent, neon, light Visual card background and borders.
accent / color Hex color, e.g. #8b5cf6 Accent brand color for stream number and progress fills.
goal streams, hours, chatters Which milestone metric to target in the goal bar.
title Text, e.g. STREAM STATS Custom card header title.
hideStreak 1 Hide the flame streak badge.
hideHours 1 Hide total broadcast hours.
hideStats 1 Hide chatters and messages counts.
hideGoal 1 Hide the goal progress bar section.
