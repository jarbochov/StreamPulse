StreamPulse Chat Bot

Settings BETA

Replies are sent as your SocialStream account, starting with the tag. Messages that start with the tag are never treated as commands. Mods are detected from SocialStream chat data when it includes them; usernames listed here are always treated as mods.

Commands

Responses use the same {{placeholders}} as overlays, for example Now playing: {{track}} by {{artist}}. Use {{args}} for whatever follows the command. Use \n for a second message.

Quotes

Chat: !quote random, !quote 12 by number, !quote word search, !quotes count. Mods: !addquote text and !delquote 12.
