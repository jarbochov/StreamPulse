StreamPulse Chat Bot BETA

Settings

Replies are sent as your SocialStream account, starting with the tag. Messages that start with the tag are never treated as commands. Mods are detected from SocialStream chat data when it includes them; usernames listed here are always treated as mods.

Troubleshooting

Shows what SocialStream sent for recent chatters and whether they count as mod or subscriber.

Commands

Responses use the same {{placeholders}} as overlays, for example Now playing: {{track}} by {{artist}}. Use {{args}} for whatever follows the command. Use \n for a second message.

Quotes

Chat: !quote random, !quote 12 by number, !quote word search, add details (e.g. !quote 12 details) to also show game, author and date, !quotes count. Mods: !addquote text and !delquote 12.

Quote commandsWho can use them and cooldowns

Import accepts a JSON export or a text file with one quote per line. Duplicates are skipped.

Variables and counters

Use {{var.name}} in chat replies and custom overlays. Set them here, via the API (/api/variables) or Companion. Counter endpoints: POST /api/variables/NAME/increment, /decrement, /reset (optional body {"amount": 5}).

Timed messages

Send a message every N minutes, every hour at a minute past, or daily at a set time. "Only if chat active" skips the message unless at least that many chat messages arrived since it last ran, so the bot never talks to an empty room. Timers only run while the bot is on.

Word triggers

Reply when chat contains certain words. Use {{user}} for the chatter's name. Each trigger has its own cooldown; the first matching trigger wins.
