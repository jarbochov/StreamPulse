StreamPulse Alerts

How alerts work

  1. Make a rule on the left: pick what triggers it (a follow, 500 bits, a raid…).
  2. Choose what to show: text, an image/GIF/video and a sound. Add several variants to mix it up.
  3. Save, then press ▶ Test on a variant. Tests play on any open overlay and in the overlay editor canvas.
  4. Add an Alert box to a custom overlay and use it as an OBS browser source. Alerts only appear there.
