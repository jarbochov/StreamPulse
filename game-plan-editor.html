StreamPulse Game Plan

Add a game

Type the game's name and StreamPulse looks up the cover, release year and genres from IGDB. Drag cards to reorder or move them between lists. Changes save automatically. The game you're currently streaming (from your Twitch category) is marked Now playing.

Create your own lists (e.g. “Co-op nights”, “Horror picks”) and pick them in the Game list element.

Use these in overlays with the Game list element in the custom overlay editor.
