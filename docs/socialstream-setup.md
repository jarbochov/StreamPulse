# Bring your chat into the show

StreamPulse works with SocialStream Ninja to bring chat and supported engagement activity into your production workspace. That connection can support session history, community tools, chat commands, and other features built around what’s happening with your audience.

SocialStream Ninja handles chat aggregation across a range of platforms; StreamPulse currently focuses on Twitch. The two tools complement one another: keep using SocialStream Ninja for the chat experience you prefer, and use StreamPulse when you want planning, overlays, alerts, and session tools alongside it.

With Twitch EventSub connected, new and returning subscriptions also reach session history without requiring a shared chat message. SocialStream Ninja remains the source for ordinary chat capture.

The connection method depends on how you run SocialStream Ninja, so the [quick start](quickstart.md) is the best place to begin. For more about the rest of the toolkit, see [StreamPulse features](features.md).

Already installed? You can find **Docs** and **API Reference** in the app navigation.
