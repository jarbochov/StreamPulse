# StreamPulse on your desktop

The StreamPulse desktop app brings the dashboard and production tools into a standalone app for macOS and Windows. Keep it open beside OBS, or close the window and leave StreamPulse running in the background while your broadcast uses its overlays.

The current release is **0.14.0**. Downloads include macOS builds for Intel and Apple Silicon in DMG and ZIP formats, plus a Windows installer and portable executable. macOS builds are currently unsigned, so macOS may show a security warning when you open one.

For download details and a first-run introduction, visit the [quick start](quickstart.md). See the [StreamPulse features](features.md) to explore what the app can do.

Already installed? **Docs** and **API Reference** are available from the app navigation.
