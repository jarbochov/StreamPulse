# StreamPulse Documentation

Welcome to the official documentation for **StreamPulse**, the ultimate self-hosted broadcast companion and overlay suite for [SocialStream Ninja](https://socialstream.ninja/) and Twitch.

StreamPulse turns your live broadcast data into cinematic OBS browser overlays, actionable community analytics, and hands-on production tools.

---

## Documentation Sections

### Getting Started
- **[SocialStream Ninja Setup](socialstream-setup.md)**: Step-by-step walkthrough for installing the extension, enabling the WebSocket API, and connecting to StreamPulse.
- **[Bitfocus Companion Integration](companion.md)**: Hardware controls, Stream Deck actions, live variables, and feedbacks.

### Overlays & Studios
- **[Custom Overlay Studio Guide](custom-overlays.md)**: Visual layer designer, WebKit punchouts, WebGL retro display shaders, GPU media filters, and animated borders.
- **[Clips Beta](clips-beta.md)**: Chat velocity spike detection and automated marker capture.
- **[Server Management](server-management.md)**: Configuration, atomic backups, and background service execution.

### Technical & Architecture
- **[Architecture & Routing](architecture.md)**: Cascading static router, componentized services, domain route controllers, and WebSocket manager.
- **[HTTP API Reference](api-reference.md)**: Complete REST API documentation for session lifecycle, randomizer, timers, and overlays.
- **[Developer Guide](developer-guide.md)**: Setting up a local development environment, running ESLint and test suites, and UI design standards.
